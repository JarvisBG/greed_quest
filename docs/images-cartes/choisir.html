Images des cartes de Greed Quest

119 cartes de notre banque (100 désignées, 13 sorts, 6 objets), avec toutes les images trouvées sur le wiki des fans pour chacune. L’image encadrée est choisie d’office, dans cet ordre : anime 2011, anime 1999, manga.

  1. Fais défiler jusqu’en bas pour que toutes les images se chargent.
  2. Si tu préfères une autre image pour une carte, clique dessus. « Aucune » laisse le filigrane.
  3. Dans Chrome : Ctrl + S, type « Page Web, complète », et enregistre dans docs/images-cartes/brutes/. Toutes les images et tes choix sont enregistrés d’un coup.
  4. Préviens Claude : il découpe, convertit et range tout lui-même.

Tes choix sont aussi gardés dans ce navigateur. « Copier mes choix » sert de secours si l’enregistrement se passe mal.
